# EDGEdir

An animation director for Cyberpunk 2077, in the EDGE family of modding tools: design and stitch animations and acting sequences for the game's characters (NPCs), and play them in the running game.

> **Preview, not ready for use yet.** This first build has the side bar and its views only. The design comes next.

Needs Windows and Cyberpunk 2077.
